# Redirect Guard v1.4

### What's New in v1.4

#### Added
- **Dedicated How It Works Dialog**: Moved the detailed explanation of how Redirect Guard works, Android security limitations, and the role of Shizuku into a separate dialog accessible through a button in the About screen.
- **Companion Redirect Tester Link**: Added a direct button in the About dialog to download the companion Redirect Tester tool from GitHub releases.
- **Direct Donate and Privacy Links**: Added direct buttons in the About dialog to open the donation page and privacy policy on the official website.

#### Fixed
- **Confirmation Dialog Button Visibility**: Fixed red button text color visibility in dark mode on the redirect confirmation dialog.

For full version history and previous release notes, see [CHANGELOG.md](https://github.com/rdevz-ph/RedirectGuard/blob/main/CHANGELOG.md).

### Features
- Deep link and app redirect interception using Android Accessibility Service
- Choice between Confirmation Prompt and Instant Auto-Return modes
- Reliable process termination for intercepted apps via Shizuku
- Dedicated Applications screen with search and category filters (All, Guarded, Whitelisted, Shopping Presets, User Apps, System)
- Automatic sync between global protection switches and individual application settings
- Automatic conflict resolution between guarded and whitelisted applications
- Smart shopping presets that adapt to installed apps on the device
- Automatic exclusion for home screens, app drawers, and system components
- Guarded app selection with presets for common shopping apps
- Interactive confirmation dialog with safety timer
- In-app live activity and debug log viewer with filter toggles and search
- Floating Material 3 Expressive toolbar with integrated refresh action
- Crash reporter with line preservation and direct GitHub issue filing
- Shizuku integration for one-tap permission setup and app termination
- Accessibility service health checker with one-tap enablement and stuck state clearing
- Optional Redirect Tester companion app for testing redirects safely
- Modern Material 3 user interface with dynamic theme support

### Requirements
- Android 7.0+ (API 24+)
- Accessibility Service permission
- Display over other apps permission (SYSTEM_ALERT_WINDOW)
- Shizuku (running and authorized to terminate redirected apps)

### Installation & Setup Guides
Download the APK from the assets below, install it, and grant the Accessibility Service, Display over other apps, and Shizuku permissions when prompted.

> [!NOTE]
> **Which APK should I download?**
> - **Release APK (`RedirectGuard-*-release.apk`) [Recommended]:** Signed with the developer's official release key. Use this build if you want seamless in-place updates from GitHub in the future without needing to reinstall.
> - **Debug APK (`RedirectGuard-*-debug.apk`):** Signed with the default Android SDK debug key generated by automated CI builds. Useful for testing, but switching to a release build in the future will require uninstalling first due to Android signature verification.
> - **Redirect Tester (`RedirectGuardTester-*-release.zip`):** An optional companion tool packaged as a ZIP archive to prevent app store indexers from mistaking it for the main app. Extract the ZIP to install the companion tester APK and verify Redirect Guard safely.

> [!WARNING]
> If you use apps or games that rely on shortcuts or redirects to other apps (such as opening messages from notifications in Messenger, or games that require browser sign-in), do not enable **Guard All External Apps**. Keep that setting disabled and only add specific apps that cause unwanted redirects, such as shopping apps, to your guarded apps list.
