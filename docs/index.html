warning Important Note on Window Detection
Redirect Guard uses Android Accessibility Service and Shizuku to detect unwanted app launches and immediately terminate redirected processes. Because Android window detection happens after an app begins to open, a redirected app may briefly appear on screen before being closed.
check_circle Testing with Redirect Tester Companion
Want to test or verify app functionality? Please use Redirect Tester (RedirectGuardTester-*-release.zip), an optional companion tool packaged as a ZIP archive to safely test common shopping app redirects. Extract the ZIP archive to find and install the companion tester APK.

Core Capabilities

Take Back Control Over App Transitions

checklist

Dedicated Setup Wizard

Guides first-time configuration with an interactive checklist to verify permissions before entering the dashboard, complete with one-tap configuration via Shizuku.

notification_important

Permission Confirmation Prompt

Displays an interactive alert dialog asking whether you want to open the target app or remain in your current app, complete with a safety countdown timer.

link_off

Deep Link Interception

Catches unauthorized deep links triggered by web banners, embedded advertisements, and redirect scripts before they take over your screen.

terminal

Process Termination via Shizuku

Uses elevated Shizuku shell access to terminate unwanted external application processes directly, safely returning you to your originating app.

swap_horiz

Two Interception Modes

Choose between Ask Confirmation for manual control with app icons and names, or Instant Auto-Return for automatic instant termination without prompts.

apps

Dedicated Applications Screen

Search, filter, and customize guard and whitelist settings for individual installed applications with instant package search and category filter chips.

rule

Conflict Prevention & Presets

Guarding an app automatically removes it from the whitelist and vice versa. Presets for shopping apps restore seamlessly when global guard is toggled off.

verified_user

Smart Launcher Whitelist

Intelligently distinguishes between accidental ad redirects and intentional launches. Opening apps from home screens, app drawers, or recent apps is never blocked.

history

Activity & Debug Log Viewer

Keep track of intercepted events with timestamps, source apps, target apps, and action logs, featuring live text search and clipboard export.

health_and_safety

Accessibility Health Monitoring

Automatically detects if Android killed or desynced the background accessibility service, with options to force stop, re-enable via Shizuku, or open system settings.
